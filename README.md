# Simple AI Data Preprocessing

This Python script demonstrates a basic data preprocessing pipeline for AI development. It simulates raw data, splits it into training and testing sets, and then applies scaling to numerical features and one-hot encoding to categorical features using scikit-learn's ColumnTransformer.

## Language

`python`

## How to Run

Save the code as `gstack_preprocessing.py` and run it from your terminal using `python gstack_preprocessing.py`.
